# 阶段 0：任务范围

## 项目目标

建设名为 `bill-daily` 的智能体工作流插件，用于票据市场日频四模块日评工作流。工作流应保证数值由确定性代码计算并逐项对账，生成方与核验方分离，发布前须经人工批准。最终输出仅供研究参考，不构成报价指令。

## 整体范围

- 以日频数据为输入，保留原始数据、快照及必要证据，确保来源和处理过程可追溯。
- 通过确定性代码完成指标计算与逐项对账，不以生成模型替代数值计算。
- 将日评生成与独立核验分为不同角色，核验未通过时不得进入发布环节。
- 发布前设置人工批准关口；未经明确批准，不对外发布。
- 输出日评及相应核验材料，并明确研究参考属性。

## 阶段 0 范围

本阶段仅建立插件清单、目录骨架、目录职责和任务边界，并配置版本控制忽略规则。

本阶段不包含：

- 数据获取、清洗、计算或对账实现；
- 命令、Skill、Agent、提示词或策略的具体工作流实现；
- 日评正文生成、自动核验或自动发布实现；
- 测试代码、运行脚本及外部服务接入；
- 真实业务数据、密钥或凭据的写入。

四模块的具体业务名称、指标口径、数据源、对账规则和输出模板在后续阶段定义，本阶段不作假设。
